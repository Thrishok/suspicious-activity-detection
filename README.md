# Suspicious Activity Detection using YOLOv8

This repository contains the implementation of a suspicious activity detection system using YOLOv8. The project leverages the capabilities of YOLOv8 for real-time object detection to identify and flag suspicious activities.

## Introduction

Suspicious activity detection is crucial for security and surveillance applications. This project aims to develop a system that can detect suspicious activities in real-time using the YOLOv8 object detection model.

## Installation

To get started with this project, follow the steps below:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Thrishok/suspicious-activity-detection.git
   cd suspicious-activity-detection
   ```

2. **Install the required dependencies:**
   Please ensure you have Jupyter Notebook installed to run the notebooks in this repository.

## Usage

Since the repository is composed entirely of Jupyter Notebooks, you can follow along with the notebooks to understand and run the code.

### Running the Notebook

To run the notebook, open it in Jupyter Notebook or JupyterLab and execute the cells.

## Dataset

The dataset used for training the model consists of annotated images containing various suspicious activities. Ensure you have the dataset in the correct format before training the model.

## Training

Training the model is done within the provided Jupyter Notebooks. Follow the instructions and code cells within the notebooks to train the model on your dataset.

## Evaluation

Evaluate the trained model on the validation set to measure its performance. The evaluation process is also included within the Jupyter Notebooks.

## Results

The results of the model's performance, including precision, recall, and mAP (mean Average Precision), will be displayed after evaluation within the notebooks.
